Scripts

Audio: Система звука
    AudioManagers: Главные контроллеры аудио
        Data: Настройки и конфигурации аудиоменеджеров
    MusicPlayers: Проигрыватели фоновой музыки
        Data: Данные музыкальных треков и плейлистов
    SFXPlayers: Проигрыватели звуковых эффектов
        Data: Конфигурации SFX и наборы звуков

Core: Базовая архитектура проекта
    EventBuses: Система событий между системами
    Installers: Инициализация сервисов и систем
    ScriptableObjects: Базовые ScriptableObject классы
    Services: Глобальные сервисы проекта
    StateMachines: Машины состояний для логики объектов

GamePlay: Основная игровая логика
    Enemies: Логика врагов
        Data: Конфигурации врагов
    NCPs: Неигровые персонажи
        Data: Данные NPC
    Player: Логика игрока
        Data: Настройки и параметры игрока
    Units: Управляемые юниты
        Data: Конфигурации юнитов

Systems: Глобальные игровые системы
    Utilities: Вспомогательные системные инструменты
    Managers: Контролирующие классы

UI: Пользовательский интерфейс
    Data: Конфигурации интерфейса
